# 设计说明 (Design) - 个人网站

## 1. 页面结构与浏览顺序

1. **主页 (Home / About)** - 欢迎语、个人简介、技能列表、项目展示、联系方式
2. **Portfolio** - 项目作品集展示
3. **Blog Posts** - 技术博客与文章归档
4. **CV** - 个人简历

## 2. 颜色、字体与整体风格

- **主色调**：深蓝 (#2c3e50) + 白色背景，保持 Academic Pages 模板默认配色
- **字体**：系统无衬线字体 (Segoe UI / Helvetica / Arial)
- **风格**：简洁、学术、信息密度适中，强调可读性

## 3. 响应式要求

- **桌面端（≥1024px）**：侧边栏个人信息 + 主内容区布局
- **手机端（≤768px）**：单列布局，文字自动换行，无横向溢出

## 4. 关键文件映射

| 文件 | 负责内容 |
|------|---------|
| `_config.yml` | 站点全局配置、作者信息、社交链接 |
| `_pages/about.md` | 首页/关于页面内容 |
| `_data/navigation.yml` | 顶部导航栏菜单 |
| `_layouts/` | 页面布局模板 |
| `_sass/` | 样式文件 |
| `assets/` | CSS、JS、图片等静态资源 |

## 5. 保留与修改

- **保留**：模板整体布局、响应式机制、Jekyll 构建体系
- **修改**：个人信息、导航菜单、首页内容、配色微调

## 6. 图片来源与许可

- 头像：使用占位图片，后续替换为本人授权照片
- 其他素材：基于 Academic Pages 模板自带资源，遵循 MIT License
