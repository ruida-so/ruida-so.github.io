# 产品需求文档 (PRD) - 个人网站

## 1. 项目目标
建立一个可长期更新的个人学术项目主页，展示个人简介、技能、项目经历和联系方式。

## 2. 目标用户与场景
- **主要访问者**：同学、教师、未来项目伙伴或实习招聘者
- **最先寻找的信息**：个人背景、技能方向、项目经历和联系方式
- **期望印象**：专业、专注金融科技与AI交叉领域、有项目实践经验

## 3. 本期范围

### 必须包含
- **Hero/主页**：个人一句话定位与欢迎语
- **About**：个人简介与学术背景（大二金融科技）
- **Skills**：编程、AI/ML、金融工具和开发工具
- **Projects**：已完成的实验项目（反欺诈、材料纠错、Skill设计）
- **Contact**：GitHub 和邮箱联系方式
- **CV**：简历页面
- **Blog**：博客文章归档

### 本期不做
- 不实现用户登录、数据库、支付功能
- 不添加复杂后台管理
- 不采集访客隐私数据
- 不引入额外 JavaScript 框架或依赖

## 4. 成功标准
1. 页面可通过 GitHub Pages 公开访问
2. 五个基本区块齐全，无模板占位文字
3. 导航、项目链接和联系方式可用
4. 桌面端和手机端均可正常阅读
5. 所有过程文档（PRD、Design、Checklist）齐全
6. README 记录正式链接

## 5. 隐私边界
- 不公开身份证号、住址、私人手机号
- 不公开课程邀请码和 API Key
- 使用匿名邮箱作为公开联系方式
