# 产品需求文档 (PRD) - 个人网站

## 1. 项目定位
**个人定位**：我是 Zhao，深圳大学大二金融科技专业学生，正在探索 AI 与金融的交叉领域。
**网站目的**：建立可长期更新的个人学术项目主页，供同学、教师和实习招聘者了解我的背景和能力。

## 2. 目标访问者
- **同学/教师**：了解我的学术背景、技能和项目经验
- **实习招聘者**：评估我的技术能力和项目实践
- **最先寻找的信息**：个人简介 → 技能方向 → 项目经历 → 联系方式

## 3. 本期范围（做什么）

### 必须包含
- **Hero/主页**："Zhao | FinTech and AI" 标题 + 一句话定位
- **About**：大二金融科技背景、AI+金融兴趣方向
- **Skills**：编程（Python/SQL/JS）、AI/ML、金融分析、开发工具
- **Projects**：反欺诈风险分析、材料纠错系统、Skill设计
- **Contact**：GitHub 和邮箱
- **CV**：简历页面
- **Blog**：博客文章归档

### 明确不做什么
- 不实现用户登录、数据库、支付功能
- 不添加复杂后台管理
- 不采集访客隐私数据
- 不引入额外 JavaScript 框架或依赖

## 4. 成功标准
1. GitHub Pages 可公开访问（https://ruida-so.github.io）
2. 五个基本区块齐全（Hero/About/Skills/Projects/Contact）
3. 无模板占位文字或示例数据残留
4. 导航栏链接可点击跳转
5. 桌面端和手机端均无横向溢出
6. docs/ 三份文档 + report + screenshots 齐全
7. Git 提交记录 13+ 次，覆盖 docs/content/style/fix/clean

## 5. 隐私边界
- 不公开身份证号、住址、私人手机号
- 不公开课程邀请码和 API Key
- 使用匿名邮箱作为公开联系方式
